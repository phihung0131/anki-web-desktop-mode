# AnkiWeb Desktop Mode

Chrome extension (Manifest V3) giúp học trên AnkiWeb dễ dùng như app desktop.

## Tính năng
- Tự phát âm thanh (mặt trước, rồi mặt sau khi hiện đáp án), có lặp lại và nghỉ giữa các lần
- Thay thanh audio mặc định bằng nút tròn phát/dừng
- Phím tắt: `Space`/`Enter` hiện đáp án, `1-4` chấm điểm, `Z` hoàn tác, `M` phát/dừng âm thanh, `R` nghe lại, `F` chế độ tập trung
- Hoàn tác chấm điểm: giữ điểm vài giây trước khi gửi thật (chỉnh trong cài đặt)
- Chế độ tối, chế độ tập trung (ẩn header và nút Edit/Limits/+/-)
- Số thẻ còn lại hiển thị dạng Mới / Học / Ôn

## Cài đặt
1. Tải repo về (Code > Download ZIP) và giải nén.
2. Mở `chrome://extensions`, bật **Developer mode**.
3. Bấm **Load unpacked**, chọn thư mục vừa giải nén.
4. Tải lại trang học trên AnkiWeb.

Chạy trên `ankiweb.net` và `ankiuser.net` (trang học nằm ở `ankiuser.net/study`).
Cài đặt mở bằng nút ở góc trái dưới.
